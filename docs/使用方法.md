# CAD插件平台 — Claude Code 使用指南

## 技能（Skills）

### `frontend-design` — 前端设计升级技能

当需要升级/美化网页界面时，Claude 会自动加载此技能中的设计规范。

**触发方式** — 在对话中说类似以下的话即可自动触发：
- "升级一下首页的卡片样式"
- "按照设计规范优化详情页"
- "给页面添加一些动画效果"
- "改善深色模式"
- "前端优化一下"

**设计方向**：
- 现代卡片风格 + 大圆角 (16px)
- 柔和阴影 + 悬停动效
- 主色 `#6366f1` (Indigo) + 琥珀色强调
- 毛玻璃导航栏/页脚
- 微交互动画（悬停上移、淡入、按钮回弹）
- 响应式适配（768px、480px 断点）

**规范文件**：`.claude/skills/frontend-design/frontend-design.md`

---

### `update-config` — 配置管理

修改 `settings.json` 配置（权限、钩子、环境变量等）。

## 文件结构说明

```
Code/
├── main.py                 # FastAPI 应用入口
├── database.py             # SQLite 数据库操作
├── dependencies.py         # 依赖注入（认证等）
├── routers/                # 路由模块
│   ├── download.py         # 下载相关接口
│   └── ...
├── templates/              # Jinja2 模板
│   ├── base.html           # 基础布局骨架
│   ├── index.html          # 首页
│   ├── detail.html         # 插件详情页
│   └── ...
├── static/
│   ├── style.css           # 全部样式（单文件）
│   └── *.svg               # Logo / 图标
├── .claude/
│   ├── settings.local.json # 项目级 Claude 配置
│   └── skills/
│       └── frontend-design/ # 前端设计技能
│           ├── skill.json
│           └── frontend-design.md
└── 使用方法.md              # 本文件
```

## 最佳实践

1. **改代码范围** — 只改 `Code/` 目录下的文件，其他目录通过同步脚本处理
2. **更新日志** — 每次改完代码，Claude 会自动写 `更新日志.md`
3. **开源同步** — GitHub 开源内容隔段时间统一整理一次
