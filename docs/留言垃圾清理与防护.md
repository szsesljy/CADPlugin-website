# 留言垃圾清理与防护指南

## 一、问题根源

旧版留言接口 `POST /api/messages` 存在三个致命问题：

1. **留言直接以 `approved`（已通过）状态入库**，前台立即展示，机器人刷一条显示一条；
2. **没有任何防护**：无审核、无频率限制、无内容过滤、无验证码，脚本可以无限刷；
3. 数据库初始化迁移还会把 `pending` 强制改成 `approved`，审核机制形同虚设。

## 二、立即清理存量垃圾留言

### 方式 1：管理后台（推荐，无需登录服务器）

进入后台 → **留言管理** → 点击紫色「清理工具」按钮，出现两个功能区：

**① 删除指定 IP 的全部留言**
- 输入 IP（如 `1.2.3.4`），点「删除该 IP 全部留言」或「删除并拉黑该 IP」；
- 确认时需再次输入该 IP，防止误操作；
- 留言列表每一行也有「删该IP全部留言」快捷按钮。

**② 按条件批量清理**
- 按状态（已拒绝/待审核/已通过）、关键词（内容或昵称包含）、N 天前删除；
- 可选「同时拉黑留言 ≥ N 条的 IP」；
- 「清空全部留言」按钮一键清库（同样需二次确认）。

### 方式 2：服务器端脚本（适合上千条、后台卡顿的情况）

在项目根目录执行（生产环境路径为 `/opt/cad-plugin-platform`）：

```bash
# 先备份！
cp data/database.db data/database.db.bak.$(date +%Y%m%d)

# 删除指定 IP 的全部留言并拉黑
python scripts/cleanup_messages.py --ip 1.2.3.4 --block-ips

# 按状态 / 关键词 / 时间清理
python scripts/cleanup_messages.py --status rejected          # 清空已拒绝
python scripts/cleanup_messages.py --keyword 加微信           # 删含关键词的
python scripts/cleanup_messages.py --days 30                  # 删30天前的

# 清空全部并自动拉黑高发 IP（阈值5条）
python scripts/cleanup_messages.py --all --block-ips

# 任何操作前都可加 --dry-run 先预览数量
```

### 方式 3：直接 SQL（最粗暴，谨慎使用）

```bash
sqlite3 data/database.db "DELETE FROM messages WHERE ip_address LIKE '1.2.3.4%';"
```

## 三、根治：部署后的防护机制（已写入代码）

| 防线 | 说明 | 触发后果 |
|------|------|----------|
| **验证码通过即展示** | 留言填完验证码后**直接显示**，体验即时 | 正常用户留言立即可见 |
| **图形验证码** | 提交前需填写图片中 4 位字母+数字（SVG 生成，无第三方依赖），验证码**一次一用**，错了需刷新 | 没有验证码的机器人一条也发不出去 |
| **关键词过滤** | 赌博、兼职、加微信、代开发票等常见垃圾词库（可自行扩展） | 拒绝 + 自动拉黑 IP |
| **1 秒连发规则** | 同一 IP 两条留言时间差 **< 1 秒**（刷屏特征） | 第二条直接放入「已拒绝」，不展示 |
| **频率限制兜底** | 同一 IP 一小时内超过 30 条留言 | 自动拉黑 IP |
| **管理员 IP 白名单** | 后台「IP 管理」添加的 IP 留言直接通过并显示"管理员" | 管理员不受审核限制 |

所有自动拉黑都写入已有的 `blocked_ips` 表，由全站中间件立即生效；误封可在后台「IP 管理 → 解封申请」处理，或直接删除黑名单条目。

## 四、部署步骤（把修复推到生产）

1. 更新以下文件到服务器 `/opt/cad-plugin-platform/`（保持目录结构）：
   - `routers/download.py`（留言接口防护 + 1 秒刷屏规则）
   - `routers/admin.py`（按 IP 删除 / 条件清理接口）
   - `database.py`（删除强制放行迁移）
   - `templates/index.html`、`templates/detail.html`、`templates/notice_detail.html`（验证码表单）
   - `templates/admin.html`（后台清理工具）
   - `scripts/cleanup_messages.py`（服务器端清理脚本，新增）
2. 重启服务：`sudo systemctl restart cad-plugin`
3. 登录后台 → 留言管理 → 清理工具，处理存量垃圾留言（或直接跑脚本）。
4. 之后正常留言即时展示；同一 IP 1 秒内连发会自动进「已拒绝」，后台可直接清理。

## 五、扩展建议（可选）

- 关键词库在 `routers/download.py` 顶部 `SPAM_KEYWORDS` 列表维护，按需增删；
- 频率上限 `MSG_RATE_LIMIT`（默认 30 条/小时，兜底拉黑）可按需调整；
- 如果依然有定向攻击，可在 Nginx 层加 IP 限速（`limit_req_zone`），或在后台手动拉黑攻击 IP 段。
