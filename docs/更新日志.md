# 更新日志

## 2026-09-06

### 全站人机验证（滑块拼图）
- **进站门禁**：所有访客（含管理后台）未通过验证前，访问任意页面都会被引导到 `/verify` 人机验证页 —— 拖动滑块把拼图块对准缺口即通过；通过后同一浏览器 24 小时内免重复验证（时长可改 `routers/verify.py` 的 `VERIFY_TTL`）
- **拼图实时生成**：服务端用 Pillow 随机生成背景（渐变 + 半透明色块 + 模糊），在随机位置挖出圆角带咬合缺口的拼图槽并压暗为原纹理 45% 亮度，拼图块按同一蒙版从原图裁切，拼合后完全无缝；目标横坐标只保存在服务器内存（2 分钟有效），前端拿不到答案
- **防爆破**：容差 ±6 像素；一次挑战只能校验一次，错对都会作废重来；同一 IP 每分钟最多获取/尝试 20 次（超限 429）；留言板块原有的字符验证码逻辑不受影响
- **放行白名单**：`/verify`、`/static`、`/unblock`（申请解封）、`/ads.txt`、黑名单管理 API 不要求验证；Google/Bing/百度/搜狗/360/神马等搜索引擎蜘蛛与常用可用性监控 UA 直接放行，保证收录与监控正常（想"严格所有访客"时，删掉 `main.py` 中 `_SEARCH_ENGINE_HINTS` 那一段即可）
- **接口兜底**：未验证时浏览器页面请求 302 跳转验证页（原地址放 `?next=`，验证完自动跳回），API/文件等请求直接返回 403 JSON，无法绕过
- **新增依赖**：`requirements.txt` 新增 `pillow`，部署脚本会自动 `pip install`；`deploy_update.bat` 打包清单已加入 `routers/verify.py` 与 `templates/captcha.html`
